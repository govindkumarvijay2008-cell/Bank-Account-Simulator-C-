# Bank Account Simulator (C++)

A menu-driven program that simulates deposits, withdrawals, and balance checks. It rejects non-positive transactions and prevents withdrawals above the available balance. It does not connect to a real bank or save data between runs.

## Compile and run
```sh
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o bank-account
./bank-account
```
On Windows, run `bank-account.exe` after compilation.
